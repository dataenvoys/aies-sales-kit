# AI Envoy Sphere — English Sales Materials

[Polish materials](../README.md)

English-language sales resources for **AI Envoy Sphere (AIES)** — an enterprise platform for creating and managing AI agents and assistants.

Use this catalogue to select materials for business decision-makers, AI leaders, IT teams and security specialists.

## Choose a resource

The links below use suggested filenames for the English editions. Upload the PDFs using these names, or update the links to match the files in this folder.

| Resource | Audience and purpose |
|---|---|
| [AI Envoy Sphere presentation](AIES-presentation-en-v6.pdf) | A comprehensive introduction to the platform, its capabilities and applications. Suitable for sales meetings and product demonstrations. |
| [Business one-pager](AIES-one-pager-business-en-v6.pdf) | A concise overview for business decision-makers: working with company knowledge, supporting decisions, and managing access, answer quality and costs. |
| [AI leaders one-pager](AIES-one-pager-AI-leaders-en-v6.pdf) | For teams building AI agents: configuration, company knowledge, agent councils, integrations and quality evaluation. |

| [Turbo Search — Document Analytics Module](AIES-turbo-search-one-pager-en.pdf) | Turning document collections into structured data, generating reports, and passing selected data or documents to AI agents. |

## How to use these materials

- **First contact with a business decision-maker:** start with the business one-pager.
- **Product meeting or demonstration:** use the presentation, then select a relevant agent council use case.
- **Discussion with an AI leader:** share the AI leaders one-pager.
- **IT or security review:** share the IT and security one-pager.
- **Analysis of large document collections:** use the Turbo Search — Document Analytics Module leaflet.

## Keeping materials up to date

Before sharing a document with a customer, check that its product information is current.

When adding or replacing a document, update its description and link in the catalogue. If a filename or folder changes, update the corresponding relative path.

Keep this file named `README.md` in the `en/` folder, alongside the English PDFs. The link at the top points to the main repository README.
