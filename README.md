# AI Envoy Sphere — materiały sprzedażowe

Repozytorium zawiera prezentację i ulotki wspierające rozmowy z klientami o **AI Envoy Sphere (AIES)** — platformie do tworzenia i zarządzania agentami oraz asystentami AI w organizacji.

## Jak korzystać z materiałów?

* **Pierwsza rozmowa z decydentem:** rozpocznij od one-pagera dla biznesu.
* **Spotkanie produktowe lub demo:** wykorzystaj prezentację, a następnie dobierz przykład z ulotki o radach agentów.
* **Rozmowa z liderem AI:** prześlij one-pager dla liderów AI.
* **Rozmowa z IT lub bezpieczeństwem:** prześlij one-pager dla IT i bezpieczeństwa.
* **Analiza dużych zbiorów dokumentów:** pokaż materiał o Turbo Search i Module Analityki Dokumentowej.
* **Rozmowa po angielsku:** wykorzystaj anglojęzyczny przegląd platformy i zastosowań.
